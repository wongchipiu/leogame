# 奥特曼：光之密室 (Ultraman: Chamber of Light)

面向 7-10 岁儿童的密室逃脱解密游戏，把数学与英语问题融入奥特曼变身、解谜、Boss 战的玩法循环中，让孩子在玩中学习。

## 运行

```bash
npm start
# 或 node server.js
```

然后浏览器打开 http://localhost:3000

## 版本

- V1.0 MVP：核心框架 + 2 密室 + 6 奥特曼 + 题库 + 变身/解谜/Boss战
- V1.5：完整 5 密室 + 自适应难度 + 家长报告 + 成就系统
- V2.0：语文/科学密室拓展
- V2.5：多人对战模式
- V3.0：UGC 题库系统
